# Content Management System (CMS) Web Application For Global Cybersecurity Community Forum (GCCF)

## Overview

The Global Cybersecurity Community Forum (GCCF) is a CMS-based web application developed during my internship. The platform is designed to manage cybersecurity-related content, community engagement, events, and organizational information in a structured and scalable way.

It provides a dynamic system where administrators can manage website content through a secure dashboard, while users can explore information, events, and membership opportunities.

## Key Features:

### Admin Panel:

- Manage website pages and content dynamically

- Create and publish news articles

- Manage events and event details

- Control image galleries and media content

- Manage team members and organizational structure

- Approve or reject membership applications

- Handle registered users and member data

### User Features:

- View cybersecurity news and updates

- Explore upcoming events

- Apply for membership

- Access organizational information and resources

- Browse gallery and public content

### Tech Stack:

- Frontend: Next.js

- Backend: NestJS (TypeScript)

- Database: PostgreSQL

- ORM: TypeORM

- Architecture: Modular CMS-based system

### System Architecture:

- The system follows a modular and scalable architecture

- Frontend communicates with backend APIs built in NestJS

- Backend handles authentication, business logic, and data processing

- PostgreSQL is used for relational data storage

- TypeORM manages database entities and relationships


## Learning Outcomes

The internship involved a lot of technical advancement in different fields. NestJS expertise was built with respect to clean architecture principles and the creation of modular, scalable, and maintainable backend applications. Real-life experience was acquired in the development and implementation of RESTful API endpoints that respond to all major CRUD operations in different modules. Practical skills were acquired in PostgreSQL database design, which entailed schema development, table associations, and query optimization by use of TypeORM. Additionally, the experience was gained in improving the performance of the backend and optimizing queries through restructuring and modularizing code to improve the efficiency of the system and response time.
